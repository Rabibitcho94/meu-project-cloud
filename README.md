# ☁️ Meu Primeiro Projeto de Infraestrutura como Código

Este repositório armazena a configuração automatizada de um servidor na nuvem da **AWS (Amazon Web Services)** utilizando o **Terraform**.

## 🛠️ Tecnologias Utilizadas
* **Git** & **GitHub** para controle de versão.
* **Terraform** para provisionamento de Infraestrutura como Código (IaC).
* **AWS EC2** para criação do servidor virtual Linux Ubuntu.

## 🚀 Como este projeto foi construído
O projeto foi inicializado localmente via Git Bash, configurado com chaves de assinatura digital e conectado com sucesso ao repositório nuvem.
Use o código com cuidado.
